# Customer Churn Prediction

## About the Project

This project predicts whether a customer is likely to leave a company using Machine Learning.

The project uses customer information such as tenure, contract type, monthly charges, internet service, payment method, and other customer details to predict churn.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Matplotlib
- Seaborn
- Streamlit

## Machine Learning

Different Machine Learning models were trained and evaluated to find the best-performing model.

The selected model is used to predict customer churn through a Streamlit web application.

## Project Features

- Data Cleaning and Preprocessing
- Exploratory Data Analysis
- Feature Engineering
- Machine Learning Model Training
- Model Evaluation
- Customer Churn Prediction
- Interactive Streamlit Web App
